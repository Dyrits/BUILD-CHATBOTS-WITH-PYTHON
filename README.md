# Build Chatbots with Python

Projects from the Codecademy "Build Chatbots with Python" course.

## About The Project

The course goes from Python basics to creating chatbots with deep learning. This repository contains the course projects, organized by section:

- 01 - Introduction to Python and Chatbots
- 02 - Python Data Structures and Loops (Looping Coffee Chatbot)
- 03 - Rule-Based Chatbots
